## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*
*Source: `.specify/memory/constitution.md` v2.0.0*

- **I Feature-first Clean Architecture**: Feature lives under `lib/features/<name>/` with `domain/`, `data/`, `presentation/`. Domain imports no Flutter UI, Dio, or `data/`. Presentation imports no datasource or repository impl.
- **II Scoped DI**: App-wide types stay in `ServiceLocator.init()`. Feature types register via `register*` in `<feature>_injection.dart` and bind at the route with `FeatureScope`. Cubits are `registerFactory`; use cases/repos/datasources are `registerLazySingleton`. No `new` of those types in widgets.
- **III Cubit/Bloc presentation**: Widgets dispatch `context.read<Cubit>().f…()` only. States are sealed (`ApiCallState<T>` unless a different sealed hierarchy is justified). No network/JSON in widgets.
- **IV `Either<Failure, T>`**: Repositories return `Either` from `package:either/either.dart`. DataSources throw `AppException`. Cubits `.fold()` both branches.
- **V Entities vs models**: JSON stays on models that extend/map to pure domain entities. `*Params` co-located with the use case.
- **Quality & Flutter**: Clean-code/SOLID/null-safety rules in `.cursor/rules/` apply. Use existing local packages (`either`, `themes`, `language`, `screen_util`, `field_validator`). `flutter analyze` must be clean. Use-case and Cubit tests required.
